Train AI together. Share no patient data.

A privacy-first federated-learning workspace with PyTorch training, clipped and noised gradients, weighted FedAvg, and a verifiable hash-chained audit ledger.

Live prototype: PyTorch trains on synthetic data across isolated demo clients with clipped/noised gradients. No patient data is used. A separate Flower server/client mode is included.

Architecture

🏥

Hospital nodes

Conceptual node representing an institution that would train locally; this demo uses no X-ray or patient data.

🔒

Differential privacy

Per-example gradients are clipped and Gaussian noise is added before updates; ε uses a conservative Gaussian RDP composition bound.

🧠

Flower aggregation

Three isolated synthetic clients train locally in PyTorch; the server combines weights with sample-weighted FedAvg. A standalone Flower server/client mode is also included.

⛓️

Blockchain audit

Entries include linked hashes to demonstrate a hash chain; the local database is not a production blockchain.
